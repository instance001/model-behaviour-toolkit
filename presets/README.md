# Presets

Presets are ready-to-use combinations of the core modules for common types of work.

If you are brand new to this repo, read [../docs/user-manual.md](../docs/user-manual.md) first.

## Available Presets

- [coding.md](coding.md)
- [research.md](research.md)
- [creative.md](creative.md)

## How To Use Them

1. Start with [starter-bundle.md](../bundles/starter-bundle.md) if you want a general default.
2. Switch to a preset when the work has stronger domain-specific needs.
3. Add [reset-bundle.md](../bundles/reset-bundle.md) when drift or context loss shows up.

## Composition Model

- Bundles are broad default setups.
- Presets are role-specific behaviours.
- Modules are smaller building blocks you can mix manually.
