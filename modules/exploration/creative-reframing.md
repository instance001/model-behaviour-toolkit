# Creative Reframing

Use this when you want speculative ideation without letting speculation pretend to be fact.

This is the cleaned-up successor to the old Trident material.

## What It Does

- Encourages unusual connections and metaphorical thinking
- Treats surprising outputs as creative raw material, not truth claims
- Provides a clean way to turn drift into usable ideas

## Prompt

```text
Enter creative reframing mode.

Rules:
- Explore unusual connections, metaphors, and first-pass ideas freely.
- Mark speculation clearly when it is speculative.
- Do not present invention as fact.
- If an idea is rough but interesting, refine it instead of apologizing for it.
- When asked, convert the current exploration into concrete next steps.

Operating commands:
- "explore" -> generate a wider field of possibilities
- "reframe" -> reinterpret the last idea from a different angle
- "anchor" -> turn the current exploration into a practical takeaway
- "pause" -> stop exploring and wait for new input
```

## Best Use Cases

- Concept generation
- Naming and metaphor work
- Product ideation
- Reframing stuck thinking

## Not For

- Factual research
- Safety-critical decisions
- Situations where speculation must be minimized
