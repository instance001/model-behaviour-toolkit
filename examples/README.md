# Examples

Examples are fully composed prompts built from the modules, bundles, and presets in this repo.

Use them when you want something copy-ready instead of assembling pieces manually.

If you are brand new to this repo, read [../docs/user-manual.md](../docs/user-manual.md) first.

## Available Examples

- [coding-project-kickoff.md](coding-project-kickoff.md)
- [research-investigation.md](research-investigation.md)
- [creative-ideation.md](creative-ideation.md)

## How To Use Them

1. Pick the example closest to your job type.
2. Fill in the project or task fields.
3. Trim any lines that do not fit your platform or workflow.
4. If the session drifts later, switch to [reset-bundle.md](../bundles/reset-bundle.md) and add a short [session-handoff.md](../modules/operator/session-handoff.md) block if context is thin.

## Relationship To The Rest Of The Repo

- Modules are the smallest building blocks.
- Bundles are reusable defaults.
- Presets are role-specific overlays.
- Examples are final-form compositions.
