# Bundles

Bundles are paste-ready combinations of the lower-level modules.

If you are brand new to this repo, read [../docs/user-manual.md](../docs/user-manual.md) first.

## Available Bundles

- [starter-bundle.md](starter-bundle.md)
- [reset-bundle.md](reset-bundle.md)

## Recommended Order

1. Start with [starter-bundle.md](starter-bundle.md) for normal use.
2. Add a preset from [../presets/README.md](../presets/README.md) when the work becomes domain-specific.
3. Use [reset-bundle.md](reset-bundle.md) when tone, continuity, or project focus drifts.
